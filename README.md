# System Prompt Manager · 로그인 (FE 프로토타입)

화면과 동작을 보여주기 위한 프론트엔드 프로토타입입니다. **서버·DB와 연결되어 있지 않습니다.**

- 어떤 아이디·비밀번호로도 로그인됩니다. 로그인은 새로고침해도 유지되고, 로그아웃하면 풀립니다.
- 아이디에 `pending`이 들어가면 승인 대기 안내창, `rejected`가 들어가면 반려 안내창이 뜹니다. `viewer`가 들어가면 Viewer(투표만 가능, 나머지 읽기 전용)로 로그인됩니다(시연용). 예: `pending@webtoon.com`
- Image 화면 데이터는 메모리에만 있어 새로고침하면 샘플 데이터로 돌아갑니다.
- 권한 신청은 어디에도 저장되지 않고, 신청 완료 안내만 띄웁니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 로그인 화면, ID 등록 및 권한 요청 모달, 신청 완료·승인 상태 안내, 로그인 후 Home 화면 |
| `style.css` | 스타일 |
| `app.js` | 로그인·화면 이동·공통 동작. 서버 호출은 `callApi()` 목업 하나로 모여 있음 |
| `image.js` | Image 화면(Feature / BYK / Gen Prompt 탭의 프롬프트 버전·실험 관리) |

빌드 과정이 없는 정적 파일입니다. `index.html`을 브라우저로 열거나 Vercel 같은 정적 호스팅에 그대로 올리면 됩니다.

## 화면 흐름

1. **로그인**: ID(회사 이메일)·PW 입력 → 로그인 → Home 화면(LLM, Image 버튼). Image를 누르면 Feature / BYK / Gen Prompt 탭에서 프롬프트 버전과 실험을 관리합니다. 버전은 실험전 → 실험중(투표) → 실험완료(Final 다듬기) → 최종(잠김) 순서로 진행합니다. 승인 대기·반려 계정이면 안내창(문의 담당자 표시)
2. **ID 등록 및 권한 요청**: 이름·아이디·비밀번호·권한 입력 → 권한 신청하기
3. **신청 완료 안내**: "권한이 신청되었습니다. 관리자 승인이 완료되면 로그인이 가능합니다." → 확인 또는 X로 닫으면 로그인 화면

## 입력 규칙 (화면에서 검사함)

| 항목 | 규칙 |
| --- | --- |
| 이름 | 1~100자 |
| 아이디 | `@webtoon.com` 이메일만 |
| 비밀번호 | 영문, 숫자, 기호를 모두 포함해 8자 이상 |
| 권한 | `Editor` 또는 `Viewer` |

## 개발자 인계

백엔드 연결에 필요한 API 규격, 요구사항, 정해지지 않은 사항은 [HANDOFF.md](HANDOFF.md)에 정리되어 있습니다.
